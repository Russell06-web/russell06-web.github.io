## 待辦：GitHub 帳號整體設定（非單一 repo）

這些不屬於任何單一 repo 的 Settings，需要到 GitHub 個人檔案設定：

- **Pinned repositories**：建議把上面 6 個 repo 全部釘選在個人檔案首頁（最多 6 個，剛好符合），順序建議跟這份文件一致（portfolio 放最前面）
- **個人檔案 bio／README**（`Russell06-web/Russell06-web` 這個特殊 repo，如果尚未建立）：可以放一句話定位＋作品集連結，非必要但能提升第一印象
